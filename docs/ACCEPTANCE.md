## 已知边界

- 二级题型需人工确认；不做 OCR、题干图像理解、官方解析生成或错因推断。
- PDF 起止页与异常字段需要人工核对；共用材料可自由翻页浏览。
- 校验表使用显式保存；复盘编辑器自动保存且有本地失败草稿。
- 当前为单人本地应用，同一题在多个标签页并发编辑以最后提交为准；恢复前关闭其他编辑页。
- JSON 完整恢复替换全部本地数据，要求二次确认及事前备份；上限 120 MB。
- 前端完整组件/图表包会产生构建体积提示，不阻断本地运行。
